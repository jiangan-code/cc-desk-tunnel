多设备集成使用实际服务、TLS/WSS、生产 relay 模块、OpenSSH、Bash 和 PTY。两台设备的同一 `/shared/project` 映射到各自临时目录，创建同名 marker 文件并写入不同内容，再分别读取、删除；另一设备文件保持完整，输出不会发到另一连接。

7 项集成用例还覆盖：

- 相同服务地址和令牌同时认证，Linux/macOS 平台声明及同路径会话隔离。
- A 掉线并续接，A 与 B 已开始的命令完成；A 退出后 B 继续执行。
- 错误设备密钥、跨设备会话读/改/删/导出、终端控制、续接密钥、relay 密钥和通道注册被拒绝。
- 同身份重复连接拒绝；人为阻塞 A 的旧通道清理时 B 命令继续，新 A 等待旧清理结束；旧回调不能删除新租约。
- 旧协议 12 独占兼容，旧历史不被新设备自动认领。
- 两套生产连接桥读取各自私有身份文件并同时接入。
- A 超过宽限期后以同一设备身份恢复原生会话 ID，B 的长命令持续运行。

模型 CLI 使用确定性替身，依据服务生成的真实 SSH 配置执行命令。原生历史恢复使用测试 JSONL 夹具。生产连接桥确实运行，但未启动完整交互 ccdt 或 Electron，未在两台真实 Mac/Linux 电脑上验收，也没有模型调用。后续实际模型验收会消耗账号额度，执行前需用户同意。
